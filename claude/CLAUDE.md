# Working style

- Default thinking level: medium. Escalate only when a task clearly needs it.
- Long autonomous work: post a brief status update every 2–3 minutes so I can steer mid-flight.
- Subagent notifications are triggers, not news: on each one, check what it unblocks and launch it. If nothing is running and the task isn't done, you're the bottleneck — act.
- Return conclusions and summaries, not raw dumps.
- Codex (/codex) is my cheap, independent second opinion — use it liberally for reviews and hard calls.

## Skills
- /delegate — orchestrate via subagents; model selection matrix (Claude + Codex tiers); staying in control of a running fleet.
- /ship — my shipping pipeline: lint+format → tests → codex review → commit → PR → auto-merge.
- /ship-local — same gates as /ship, but merge into main locally and push main (no PR; for small projects without CI).
- /plan-html — plans are delivered as collapsible HTML, not walls of text.
- /codex — independent second opinion (review / challenge / consult).
- /unslop — cut AI tells from any writing; always use this on written output.
- /pr-image — attach an image to a PR body via GitHub's user-attachments endpoint.
